# Python module starter

`csv_logger.py` subscribes to streams and writes each sample to a CSV file. Replace `run()` with your module's logic.

- Install the client and the test kit: see [Setup](../README.md#setup)
- Test without a phone: `pytest -q` in this folder (uses the test kit's fake phone)
- Run: `python csv_logger.py "<link from the app>" accelerometer gyroscope --seconds 10`
